# What's new in v3

- Open the TUI with `tagselecta`, or pass a file or directory directly. CLI commands still work as before.
- A refreshed layout groups the explorer, metadata, and status into panels.
- Scroll metadata with `J` and `K`; the position resets when you switch files. The panel also shows the entry count.
- Customize colors, selection and change symbols, and metadata icons in the config file.
- Optional Nerd Font icons can be enabled if your terminal supports them.
- Press `Esc` to close the picture view, as well as help screens.
- The old header and its `header_visible` setting have been removed.
