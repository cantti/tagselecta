# What's new in v3

- Open the TUI with `tagselecta`, or pass a file or directory directly. CLI commands still work as before.
- A refreshed layout groups the explorer, metadata, and status into panels.
- Scroll metadata with `Shift+J` and `Shift+K`; the position resets when you switch files. The panel also shows the entry count.
- Hide or show metadata with `m` or `:togglemetadata`. Hiding it gives the explorer the full available height.
- Use `:help` (`:h`) for general help, `:help edit` for command-specific help, `:help templates` for template examples, and `:help keymap` for shortcuts.
- Completion now includes TUI command names, macro names for `:macro` and `:run`, and help topics. Suggestions refresh when you open files.
- Customize colors, selection and change symbols, and metadata icons in the config file.
- Optional Nerd Font icons can be enabled if your terminal supports them.
- Press `Esc` to close the picture view, as well as help screens.
- The `h` and `?` shortcuts now open help instead of toggling it closed. Use `Esc` to close help.
- The old header and its `header_visible` setting have been removed.
